# 研报 → 单文件 HTML

**一句话**：吃一份 Markdown，吐一个**自包含**的 `.html`——离线能开、发给别人不丢样式、正文里的 `[N3]` 引用可点跳到文末来源。

## 何时调用

- `industry-research` 写完 `.md` 之后（**自动调用**，见该 skill 步骤 7）。
- 用户说「做成网页 / 转 html / 方便查看 / 导出一份好看点的版本」。
- 任何 Markdown 长文档想要可读网页时。

## 怎么调用

```bash
python3 ~/.claude/skills/report-html/build.py 报告.md
python3 ~/.claude/skills/report-html/build.py 报告.md -o 自定义.html --title "标题"
python3 ~/.claude/skills/report-html/build.py 报告.md --strict    # 把警告也当错误
```

- 默认输出 = 输入同名 `.html`。
- **退出码**：`0` 通过 · `1` 自检不合格（**已写出 HTML 前的拦截，不会落盘半个文件**）· `2` 用法错误。
- stdout 给一行统计（标题/引用/来源/表格/体积），stderr 给警告与错误。

## 输出长什么样

- **单文件自包含**：CSS 与脚本全部内联，零外部请求。断网、拷给别人、丢进 U 盘都能开。
- 左侧**固定目录**（h2/h3），滚动自动高亮当前章节；窄屏折叠成「目录」按钮。
- 正文 `[N3]` 渲染成绿色徽章，**点击跳到文末对应来源并高亮那一行**。
- 表格套横向滚动容器 + 斑马纹 + 表头吸顶；深/浅色跟随系统。
- **打印友好**：`Cmd+P` 直接转 PDF（自动隐藏目录、展开表格）。

## 支持的语法

标准 Markdown 子集：ATX 标题 h1–h6、围栏代码块、水平线、**嵌套**有序/无序列表 + 松散列表 + 缩进续行、
**嵌套**引用块、表格（含 `:---:` 对齐与单元格内 `<br>`）、粗体/斜体/删除线/行内代码/反斜杠转义、
`[文字](url)` 与裸 URL 自动链接、`![图](url)`（**降级为链接**，见下）。

本 skill 的特有约定：**`[X9]` 形式的引用 ID 自动变成跳转锚点**，附录里 `- X9 / 标题 / 发布方 / …` 形式
的条目自动获得 `id="src-X9"` 目标。

**不支持**（会原样保留）：setext 标题（`===` 下划线式）、引用式链接、脚注、任务列表、
HTML 块、定义列表。需要时改用上述写法。

## 改样式

**改 `theme.css`，不要改 `build.py`。** 文件顶部 `:root` 与深色块是全部配色/字号变量
（底色、正文色、强调色、引用徽章色、正文字号 `--size`、目录宽度 `--toc-w`、正文最大宽 `--maxw` …），
改完重跑 `build.py` 即生效（输出时会把该文件内联进去）。

## 内置自检（写出前跑，不过就不落盘）

| 检查 | 级别 |
|---|---|
| 悬空引用：正文引了 `[X9]` 但来源锚点不存在 | **错误** |
| 残留未转换的 Markdown（`**` / `#` / `](` / 表格竖线 / 反引号） | **错误** |
| 输出不自包含（`<link>` / `<script src>` / `@import` / 远程图片） | **错误** |
| 目录锚点缺失 | **错误** |
| 来源已列出但正文未引用 | 警告（`--strict` 下升为错误） |

## 已知边界

- **图片降级成链接**：为保证输出自包含，`![alt](url)` 不渲染远程图片，改为一个链接。要插图请自行改 CSS/HTML。
- **`\*\*` 这类转义会与「残留 `**`」检查冲突**：正文若真有字面量 `**`，自检会误判为残留。此时用 `&#42;` 或改写措辞。
- **只做静态渲染**，无交互、无搜索框。要交互另说。
- **依赖解释器**：需要 `python3`（纯标准库，无第三方包）。
