# 行业调研助手 · 资料渠道调研报告

> 状态：调研初稿（基于 web 检索与领域知识整理）
> 日期：2025-08

## 1. 渠道全景总览

行业调研的数据需求可归纳为六类：**宏观环境、产业供需、竞争格局、企业经营、技术趋势、市场舆情**。
对应渠道按「可靠性 × 可获取性」分层：

| 层级 | 渠道类别 | 典型用途 | 可靠性 | 自动化可及性 |
|------|----------|----------|--------|--------------|
| **核心** | 官方统计 / 政府公告 | 宏观、政策、行业总量 | ★★★★★ | 中（官网/API 有限，需抓取+解析） |
| **核心** | 上市公司披露（年报/公告） | 企业经营、财务、市占率 | ★★★★★ | 高（巨潮资讯/EDGAR 有规范格式） |
| **核心** | 金融终端（Wind/Choice 等） | 一站式金融+行业数据 | ★★★★★ | 高（API 需付费授权） |
| **重要** | 券商研报 | 行业分析框架、预测 | ★★★★ | 中（多数付费；公开渠道零散） |
| **重要** | 咨询机构报告 | 市场规模、趋势（引用需谨慎） | ★★★ | 中（摘要免费、全文付费） |
| **重要** | 行业垂直媒体 | 一手新闻、公司动态 | ★★★ | 高（RSS/爬虫） |
| **重要** | 学术/专利库 | 技术趋势、前沿方向 | ★★★★★ | 高（arXiv/Semantic Scholar/Patents API） |
| **补充** | 社媒/舆情 | 消费者反馈、品牌声量 | ★★ | 高（但有噪声、需清洗） |
| **补充** | AI 检索基础设施 | 上述内容的统一检索入口 | ★★★★ | 最高（一键 API） |

## 2. 官方与权威数据源

| 渠道 | 提供内容 | 获取方式 | 成本 | 更新频率 | 备注 |
|------|----------|----------|------|----------|------|
| 国家统计局 | 宏观、工业、社零、人口等 | 官网 CSV/网页；`stats.gov.cn` | 免费 | 月度/季度/年度 | 口径权威，是交叉验证的基准 |
| 海关总署 | 进出口贸易数据 | 官网统计查询 | 免费 | 月度 | 出口产业链分析必备 |
| 中国人民银行 | 货币、信贷、社融 | 官网数据 | 免费 | 月度 | 金融/地产行业关键 |
| 工信部/发改委/能源局等 | 产业政策、行业运行数据 | 官网政策库 | 免费 | 不定期 | 政策跟踪的核心；建议做政策监控 |
| 行业协会 | 细分行业产量、销量（如中汽协、中物联、药监局） | 官网/报告 | 免费或低 | 月度/年度 | 官方统计的细粒度补充 |
| 国际组织 | World Bank、IMF、OECD、UN Comtrade、WHO、ITU、FAO | 有官方 API（如 World Bank API、UN Comtrade API） | 免费 | 年度 | 跨境/全球对比必备 |

**自动化建议**：官方源优先做「定时快照 + 结构化入库」，因其权威性决定了它们应作为交叉验证的基准（ground truth），而非唯一信源。

## 3. 证券研报与金融数据

| 渠道 | 提供内容 | 获取方式 | 成本 | 备注 |
|------|----------|----------|------|------|
| Wind / Choice / iFinD | 全量金融数据+研报平台 | 付费终端/API | 高（机构价） | 数据最全；个人订阅成本高 |
| 慧博投研 / 萝卜投研 / 朝阳永续 | 研报聚合 | 付费订阅 | 中 | 研报阅读与检索 |
| 券商公众号/官网 | 公开研报摘要与部分全文 | 爬虫/RSS | 免费 | 覆盖不全但零成本起点 |
| 雪球 / 集思录 | 投资者讨论、研报观点搬运 | 爬虫 | 免费 | 适合观点收集，非权威 |
| 国际：Bloomberg / Refinitiv | 全球市场+公司数据 | 付费 API | 很高 | 一般个人项目不需要 |
| Yahoo Finance API / Alpha Vantage / Finnhub | 行情与基本面 | 免费额度 API | 免费起 | 美股覆盖好 |

**注意**：研报含分析师预测（前瞻性、带立场），引用时应标注来源与发布时间，且不能作为事实基准。

## 4. 市场研究与咨询机构

| 渠道 | 内容 | 获取方式 | 成本 | 可靠性 |
|------|------|----------|------|--------|
| 艾瑞 / 易观 / 头豹 | 互联网、消费、科技行业报告 | 摘要免费，全文付费 | 中 | ★★★（方法论可查、数据需核对） |
| IDC / Gartner / Forrester | IT、企业软件全球数据 | 付费 | 很高 | ★★★★★（但贵，且多英文） |
| 弗若斯特沙利文（Frost & Sullivan） | 招股书引用常见的行业数据 | 付费 | 高 | ★★★★ |
| McKinsey / BCG / Bain | 战略视角、行业趋势 | 官网白皮书免费 | 免费 | ★★★★ |
| Euromonitor / Statista / IBISWorld | 全球市场规模、消费数据 | 付费订阅（Statista 有免费条目） | 中高 | ★★★★ |
| Mordor / Grand View Research | 细分市场报告 | 摘要免费 | 中 | ★★★ |

**重要提醒**：咨询机构的市场规模数据口径各异、常有夸大，**必须与官方统计/上市公司数据交叉验证**后才能采信——这正是审查机制要解决的问题（见 `03-审查机制.md`）。

| 行业垂直媒体（半导体、医药、新能源、消费等） | 细分领域一手信息 | 免费/订阅 | 免费 | 按主题预配置源列表 |
| 公司官网新闻稿 / IR 页面 | 一手公司信息 | 爬虫/RSS | 免费 | 与公告互为印证 |

**自动化建议**：建立「源列表 + RSS/爬虫 → 增量入库 → 去重 → 摘要」的资讯管道；新闻类信源只作为事实线索，最终引用应回溯到一手来源（公告/官方/原始发布会）。

|------|------|----------|------|------|

## 9. 现代 AI 检索基础设施（自动化系统的实际入口）

这是自动化调研系统真正每天调用的通道，把上面所有渠道变成统一的检索接口：

| 服务 | 用途 | 免费额度 | 付费 | 备注 |
|------|------|----------|------|------|
| **Tavily** | 面向 LLM 优化的网页搜索 API | 1000 credits/月（约 1000 次搜索） | 约 $49/月起 1000 credits/日 | GPT-Researcher 默认集成之一，返回"已清理"的搜索结果与内容 |
| **Exa** | 语义/神经搜索 + 内容抓取 | 有试用额度 | 约 $10/月起 | 适合按语义找网页（如找同类报告） |
| **Serper** | Google SERP API | 2500 次免费 | $50/百万次级 | 便宜、稳定，返回 Google 结果 |
| **Firecrawl** | 网页抓取/整站爬取→Markdown | 500 credits/月 | $16/月起 | 把网页转结构化文本，绕开解析难题 |
| **Jina Reader** | URL → Markdown | 免费额度 | 低 | 轻量网页转文本 |
| **Perplexity API / Gemini Deep Research / OpenAI Deep Research** | 直接生成带引用的研究报告 | 付费 API / 订阅 | 高 | 可以"外包"给大厂 deep research 能力 |
| Semantic Scholar API / arXiv API / Crossref | 学术检索 | 免费 | 免费 | 技术趋势 |
| Google Fact Check API | 事实核查辅助 | 免费 | 免费 | 见审查报告 |

**分层建议**：MVP 用 Tavily（或 Serper）+ Firecrawl/Jina 组合即可覆盖 80% 公开网页检索；付费专业库（Wind/知网）留到 Phase 2 按需接入。

## 10. 常见陷阱与应对

| 陷阱 | 说明 | 应对 |
|------|------|------|
| 数据口径不一致 | 同指标多源数字不同（含/不含某口径） | 记录口径元数据；以官方为准交叉验证 |
| 时效性 | 报告引用过时数据 | 强制标注数据年份；数据新鲜度检查 |
| 付费墙 | 高价值内容在墙后 | 摘要+标题入库；引导人工订阅 |
| 版权与授权 | 商用转载风险 | 只引用摘要/数据点（注明出处），不整篇转载；遵守《生成式人工智能服务管理暂行办法》等 |
| 反爬与封禁 | 高频抓取被限制 | 用合规 API 服务替代自建爬虫；限速、缓存、快照 |
| 数据质量参差 | 自媒体数据不可靠 | 信源分级；低质信源不进知识库 |
| 信息投毒 | 恶意网页给 LLM 下毒（prompt injection） | 检索内容与指令分离；输入过滤（见审查报告 §对抗） |
| 假报告/假新闻 | AI 生成内容冒充权威 | 信源白名单；域名校验 |

## 11. 推荐的渠道分层策略（供架构落地）

1. **核心层（必须接入）**：国家统计局等官方源（定时快照）、巨潮资讯+EDGAR（公告与财报）、Tavily/Serper+Firecrawl（公开网页统一检索入口）、Semantic Scholar/arXiv（技术趋势）。
2. **重要层（Phase 1-2 接入）**：行业垂直媒体 RSS 管道、行业协会、券商公开研报、招股书 PDF 解析、工商数据（企查查/天眼查）。
3. **补充层（按需）**：付费终端（Wind/Choice/知网）、咨询机构全文、社媒舆情、Statista/Euromonitor。

> 原则：**先统一检索入口 + 一手权威源，再逐步扩展垂直源**；每条入库数据记录 `来源 URL + 抓取时间 + 信源等级`，为审查机制（`03`）提供基础。
